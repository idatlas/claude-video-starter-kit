# Examples

The project files behind the course's three videos. Copy one into `projects/` to start a video
of the same kind. The media (voice, stock clips, art, recordings) isn't included; Claude makes or
downloads it again with the scripts.

| Folder | Template | What's here |
|---|---|---|
| `promo/` | promo | `script.txt` and the final `project.json` (stock IDs are in the file names: `stock/video-<id>.mp4`) |
| `explainer/` | cutout | `script.txt`, `art-prompts.md` for Gemini, and the `project.json` |
| `tutorial/` | tutorial | The `project.json` for the short test clip: cuts, zooms and every kind of note |
